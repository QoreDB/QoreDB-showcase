# TiDB

The **TiDB** driver is included in Core. It uses the MySQL protocol with its own connection identity and capability limits.

## Connect

1. Open **New Connection** and select **TiDB**.
2. Enter the host, port (**4000** by default), credentials and database or namespace.
3. Configure TLS for your endpoint, choose the environment and use **Test Connection** before saving.

TiDB Cloud hosts ending in `tidbcloud.com` are detected automatically. For a local server, select TiDB explicitly. Use the port provided by your cloud instance when it differs from 4000.

```text
mysql://USER:PASSWORD@HOST:4000/test
```

Replace the uppercase placeholders with your connection details. For compatible engines, verify the selected driver after importing a URL; the protocol alone may identify only the parent engine.

## Capabilities and limits

Query and browse tables through the MySQL protocol. MySQL routines, triggers, events and maintenance operations are not exposed where TiDB does not support them.

## Troubleshooting

If the connection fails, check the endpoint, port, credentials and certificate settings. If a control is unavailable after connecting, check the driver’s capabilities before changing permissions.
