# Azure Synapse

The **Azure Synapse** driver is included in Core since v0.1.39. It uses the SQL Server protocol with its own connection identity and capability limits.

## Connect

1. Open **New Connection** and select **Azure Synapse**.
2. Enter the host, port (**1433** by default), credentials and database or namespace.
3. Configure TLS for your endpoint, choose the environment and use **Test Connection** before saving.

Use the dedicated SQL endpoint or the serverless endpoint provided by your workspace. Hosts under `*.sql.azuresynapse.net` are detected automatically. TLS is forced.

```text
sqlserver://USER:PASSWORD@WORKSPACE.sql.azuresynapse.net:1433/DATABASE?encrypt=true
```

Replace the uppercase placeholders with your connection details. For compatible engines, verify the selected driver after importing a URL; the protocol alone may identify only the parent engine.

## Capabilities and limits

SQL queries and catalog browsing use TDS. Structured mutations, transaction controls, maintenance actions and visual DDL are disabled in QoreDB to account for differences between dedicated and serverless pools. A missing control is an intentional driver limitation.

## Troubleshooting

If the connection fails, check the endpoint, port, credentials and certificate settings. If a control is unavailable after connecting, check the driver’s capabilities before changing permissions.
