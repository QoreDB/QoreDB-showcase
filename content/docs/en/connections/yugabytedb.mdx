# YugabyteDB

The **YugabyteDB** driver is included in Core since v0.1.39. It uses the PostgreSQL protocol with its own connection identity and capability limits.

## Connect

1. Open **New Connection** and select **YugabyteDB**.
2. Enter the host, port (**5433** by default), credentials and database or namespace.
3. Configure TLS for your endpoint, choose the environment and use **Test Connection** before saving.

Use the YSQL endpoint, not the YCQL endpoint. The default database is `yugabyte`. Hosts under `*.yugabyte.cloud` are detected automatically; choose the driver manually for local hosts.

```text
postgresql://yugabyte:PASSWORD@HOST:5433/yugabyte?sslmode=verify-full
```

Replace the uppercase placeholders with your connection details. For compatible engines, verify the selected driver after importing a URL; the protocol alone may identify only the parent engine.

## Capabilities and limits

Uses the PostgreSQL protocol and catalog for browsing and SQL queries. Use port 5433 rather than the PostgreSQL default of 5432. PostgreSQL compatibility does not guarantee every extension or administrative command is available on your cluster.

## Troubleshooting

If the connection fails, check the endpoint, port, credentials and certificate settings. If a control is unavailable after connecting, check the driver’s capabilities before changing permissions.
