# KeyDB

The **KeyDB** driver is included in Core since v0.1.39. It uses the Redis protocol with its own connection identity and capability limits.

## Connect

1. Open **New Connection** and select **KeyDB**.
2. Enter the host, port (**6379** by default), credentials and database or namespace.
3. Configure TLS for your endpoint, choose the environment and use **Test Connection** before saving.

Select KeyDB explicitly. QoreDB does not probe the server to distinguish it from Redis and does not accept a dedicated `keydb://` scheme. Use `rediss://` for TLS.

```text
redis://USER:PASSWORD@HOST:6379/0
```

Replace the uppercase placeholders with your connection details. For compatible engines, verify the selected driver after importing a URL; the protocol alone may identify only the parent engine.

## Capabilities and limits

Uses the existing RESP driver for key browsing and Redis commands. The URL path is a database index, not a SQL database name. Redis driver limitations apply; KeyDB-specific administration is not a separate QoreDB feature.

## Troubleshooting

If the connection fails, check the endpoint, port, credentials and certificate settings. If a control is unavailable after connecting, check the driver’s capabilities before changing permissions.
