# MCP server

QoreDB includes `qore-mcp`, a local Model Context Protocol server for external AI tools. It shares QoreDB's engine, saved connections and credential vault. MCP access is included in **Core**; cross-database federation requires **Pro**.

## Enable access

1. Open **Settings → AI Agents** in QoreDB.
2. Explicitly allow access to each connection you want to expose. Existing and new connections are **hidden by default**.
3. Use the detected MCP binary path and the configuration snippet for your client. The settings screen also displays the binary version.
4. Restart or reconnect your MCP client, then ask it to list the available connections.

The binary is included in the desktop bundle and available as a release asset. Communication uses **stdio**: the client launches the process, with no HTTP port to open.

## Available tools

| Tool | Purpose |
| --- | --- |
| `list_connections` | List only connections explicitly exposed to agents. |
| `list_namespaces` | Discover databases and schemas. |
| `list_tables` | List tables and collections. |
| `describe_table` | Inspect columns and keys. |
| `preview_table` | Preview a limited set of rows. |
| `search_schema` | Find objects in the schema. |
| `run_query` | Execute a read-only query in an explicit namespace. |
| `explain_query` | Inspect a query plan. |
| `list_saved_queries` | Discover queries in the active workspace library. |
| `run_saved_query` | Execute a saved query with validated variables. |
| `run_federated_query` | **Pro:** join data across exposed connections. |

Schema resources use `qore://` URIs. The server also offers `audit_table`, `explain_slow_query` and `document_schema` prompts.

## Workspaces and saved queries

Start the server from a project containing a `.qoredb` workspace, or pass its directory explicitly:

```bash
/absolute/path/to/qore-mcp --workspace /absolute/path/to/project
```

Saved queries come from that workspace's library. Variables are validated and substituted as typed literals. Without a workspace, the saved-query tools cannot read a query library.

For Claude Code, you can register the binary directly:

```bash
claude mcp add qoredb -- /absolute/path/to/qore-mcp --workspace /absolute/path/to/project
```

If building from source, run this from the QoreDB repository root:

```bash
cargo build --manifest-path src-tauri/Cargo.toml -p qore-mcp --release --features duckdb-bundled
```

`QOREDB_CONFIG_DIR` selects a non-default configuration directory.

## Access controls

Sessions are always read-only. Query row caps, timeouts, rate limits and audit logging remain active, and idle sessions close after ten minutes. [Pro column masking](/docs/security/column-masking) is applied to returned data. Federated queries can only use exposed connections; the embedded DuckDB runtime cannot access local files, URLs or extensions.

<Callout type="warning">
Read-only does not mean private: an external AI client may forward the results to its configured model provider. Expose only appropriate connections, prefer restricted database roles, and configure masking when needed.
</Callout>
