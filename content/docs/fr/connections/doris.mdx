# Apache Doris

Le driver **Apache Doris** est inclus dans Core. Il utilise le protocole MySQL, avec sa propre identité de connexion et ses limites fonctionnelles.

## Se connecter

1. Ouvrez **Nouvelle connexion** et choisissez **Apache Doris**.
2. Renseignez l’hôte, le port (**9030** par défaut), les identifiants et la base ou le namespace.
3. Configurez TLS pour votre point d’accès, choisissez l’environnement et **testez la connexion** avant de l’enregistrer.

Utilisez le point d’accès aux requêtes MySQL du frontend et choisissez Apache Doris explicitement. N’utilisez pas le port HTTP d’administration.

```text
mysql://USER:PASSWORD@HOST:9030/DATABASE
```

Remplacez les valeurs en majuscules par vos paramètres. Pour les moteurs compatibles, vérifiez le driver sélectionné après import d’une URL : le protocole seul peut n’identifier que le moteur parent.

## Capacités et limites

Explorez le catalogue et exécutez des requêtes SQL. Les mutations structurées de lignes, transactions et DDL visuel sont désactivés dans QoreDB pour ce driver OLAP. La compatibilité avec le protocole MySQL ne garantit pas les mêmes fonctionnalités.

## Dépannage

Si la connexion échoue, vérifiez le point d’accès, le port, les identifiants et les certificats. Si une commande reste indisponible après connexion, vérifiez les capacités du driver avant de modifier les permissions.
